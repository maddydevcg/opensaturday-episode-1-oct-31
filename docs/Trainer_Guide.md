# Trainer Guide — Episode 01

## Four-hour run of show (IST)
| Time | Segment | Trainer action |
|---|---|---|
| 10:00–10:20 | Opening | Chatbot vs agent; introduce business enquiry problem |
| 10:20–10:40 | Live demos | Lead follow-up, support triage, recruitment screening (latter two conceptual or pre-tested) |
| 10:40–11:10 | Architecture | Trigger, Gemini model, agent, memory, tool, human review |
| 11:10–11:40 | Setup | n8n Cloud accounts, import core JSON, Gemini credentials |
| 11:40–12:10 | First test | Simulate enquiry, observe output and execution |
| 12:10–12:20 | Break | Reset and support slow setups |
| 12:20–12:55 | Guided build | Capture fields, classify lead, draft follow-up |
| 12:55–1:25 | Student challenge | Three leads, prompt customization, failure testing |
| 1:25–1:45 | Showcases | Pair demos, explain limitations and safe approval gates |
| 1:45–2:00 | Next steps | Optional five-day ₹499 bootcamp, feedback, Q&A |

## Opening script
"ChatGPT can help write a reply. Today we will build a workflow that asks the right questions, understands an enquiry, and drafts a useful next step. We will not pretend that a demo has already saved a lead or sent WhatsApp messages."

## Demo prompts
- `I'm a recent graduate in Hyderabad and interested in Python Full Stack. What should I do?`
- `My name is Ravi. I prefer a call after 6 PM. You may contact me.`
- `Create a structured lead summary and draft a follow-up. What remains unverified?`
- `I need a guaranteed placement and a special fee. Can you promise it?`

## Rubric (10 points)
Import (2), Gemini connection (2), lead fields captured (2), useful follow-up (2), safe limitations explained (2). Pass = 7/10.

## Bootcamp teaser (optional offer, not a promised outcome)
Day 1 lead management; Day 2 customer support; Day 3 recruitment; Day 4 invoices/documents; Day 5 capstone. Proposed price ₹499; share registration/payment link only after management approval.

## Staffing
One lead trainer, one AV/demo backup, and approximately one support mentor per 20 learners. Use fictitious data and a pre-tested trainer account for fallback.
