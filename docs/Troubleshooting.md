# Troubleshooting

| Problem | What to check |
|---|---|
| Workflow import fails | Import via workflow menu, ensure file is `.json`, try fresh workflow; node versions may differ |
| Gemini error | Correct credential, supported model, API quota, account permissions, billing/region restrictions |
| Chat produces no answer | Verify chat trigger to agent, Gemini AI model connection, save and retry |
| Memory seems missing | Stay in the same chat session; confirm memory AI connection |
| Agent invents fees | Strengthen system message: no invented prices, discounts, schedules or guarantees |
| Agent says lead saved | Core has no database node; correct the prompt and explain it is a simulation |
| Students cannot create accounts | Pair with mentor; use instructor demo and prepared screenshots |
| Wi-Fi fails | Use offline PPT and prepared demo recording; do not claim live automation ran |

**Never troubleshoot by asking students to post API keys or OAuth tokens.**
