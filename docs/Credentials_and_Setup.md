# Accounts and Credentials

1. Trainer: create an n8n Cloud account and confirm import works in **your tenant**.
2. Trainer: use Google AI Studio to create a Gemini API key. Confirm model availability, quota and billing/terms in advance.
3. Import `workflows/01_AI_Sales_Enquiry_Agent_CORE.json`; open the Gemini node, add credential, select a supported model, save and test.
4. Students: individual accounts/keys if available. Pair up if provider account restrictions prevent setup.
5. Keep secrets in n8n credential storage, never in workflow JSON, slides, Git, chat messages or screenshots.
6. Do not connect real Codegnan CRM, Sheets, Gmail or WhatsApp in the classroom without approval and appropriate data controls.
7. Verify Wi-Fi, projector, laptop power, browser sign-in, fallback video/screenshots and a trainer-owned tested workflow.

**Note:** Free tiers, trials, and provider limits can change. Check them on event day. The core workflow is a simulation and does not write to external systems.
